随着全球城市化进程的持续加速与机动车保有量的快速增长，城市交通系统面临着拥堵加剧、事故频发、排放超标等一系列严峻挑战。此背景下，发展智能交通实现交通流量的精准监测与预测，对于优化路网运行效率、提升出行体验、推动城市可持续发展具有重要的意义。然而，现有研究往往在模型架构的综合性、时空依赖建模的精细度以及算法研究与实际系统部署的衔接方面存在不足。为此，本研究以“理论创新-模型集成-系统实现”为主线，构建出融合深度学习与物联网平台的交通流量监测与预测解决方案。研究围绕两个层面预测任务展开，包括单一检测点的时序预测与多节点路网的时空联合预测，并最终将算法模型工程化，集成于一个基于物联网平台的监测系统中。主要研究工作与成果如下：
     
     （1）针对单节点交通流量预测，提出了融合多尺度时序卷积与稀疏注意力机制的多尺度时序增强网络（Multi-Scale Enhanced Informer, MSEInformer）模型。该模型旨在解决单一流量序列中局部短期波动与长期周期性依赖并存的问题。通过设计多尺度时间卷积网络模块并行设置不同尺度的因果卷积核，显式提取交通流在不同时间粒度下的局部时序特征。其次，为进一步增强模型对序列上下文连续性的建模能力和预测生成质量，在Informer模型的编码器解码器中集成了长短期记忆网络。在美国I-94州际公路公开数据集上的实验表明，该模型在关键指标上均显著优于基准模型。消融实验进一步证实了各模块对于提升预测精度的有效性与必要性。
     
     （2）面向多节点交通路网预测，构建了多分支时空图神经网络（Multi-Branch Spatio-Temporal Graph Former，MBSTGFormer）模型。模型为精细刻画交通网络中各节点间复杂且动态变化的空间依赖关系，采用了多分支、多视角的空间建模策略，通过动态融合门控自适应整合各分支时空信息。并引入基于时空嵌入的时序分解，并在时空嵌入中融入注意力机制优化分解效果。模型在PeMS04和PeMS08两个经典交通流量数据集上进行验证，其评估指标相比基线模型均有所提升，表明了MBSTGFormer模型其在学习复杂时空演化规律方面的有效性。
